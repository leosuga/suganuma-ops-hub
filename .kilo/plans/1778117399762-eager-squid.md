## Aprendizados críticos da sessão 2026-05-09

1. **Docker DNS interno > IP fixo**: O erro 502 após deploy foi causado pelo Caddy apontando para IP fixo do container antigo. `--hostname` + `reverse_proxy hostname:3000` resolve via DNS do Docker e elimina o problema.
2. **`typedRoutes` não é viável com BottomNav**: O `BottomNav.tsx` usa `string` em vez de literais para hrefs. Habilitar `typedRoutes` quebra o build instantaneamente.
3. **`@tailwindcss/typography` v0.5.19 é incompatível com Tailwind v4**: Não basta instalar. O plugin `@plugin "@tailwindcss/typography"` no CSS falha com `Cannot find module 'tailwindcss/dist/plugin.js'`. Aguardar versão v4.
4. **ESLint rules `react-hooks/set-state-in-effect` e `react-hooks/refs` geram falsos positivos**: Patterns comuns como `useEffect(() => setMounted(true), [])` e `queryKeyRef.current = queryKey` são sinalizados como errors. Desativar essas rules é seguro para este projeto.
5. **Deploy com Node 22 funciona**: Build no VPS com `node:22-alpine` passou sem erros. A imagem está em produção agora.
6. **Existem 9 migrations, não 10**: `0001` a `0009`. O plano mencionava 10 erroneamente.
7. **React Compiler no Next.js 16**: `reactCompiler: true` funciona (não `experimental.reactCompiler`). Requer `babel-plugin-react-compiler` instalado como `devDependency`. Build + tests passam sem alterações de código.
8. **Supabase CLI `--linked` só funciona para projetos Cloud**: Nosso Supabase é self-hosted (`api.suganuma.com.br`), não um projeto da Supabase Cloud. `--local` requer Docker daemon. Tipos manuais validados via audit são suficientes.
9. **`@next/bundle-analyzer` é incompatível com Turbopack**: O analyzer clássico não gera relatório em builds com Turbopack. `next experimental-analyze` não produziu output útil no tempo disponível.
